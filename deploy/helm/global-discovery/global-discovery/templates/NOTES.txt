cluster, export and pool; writers re-register on their next heartbeat. Use it
for development and tests only.

The server role needs the DynamoDB policy of docs/iam.md in the module
src/control-plane-services/global-discovery.{{ if .Values.serviceAccount.irsaRoleArn }} ServiceAccount

  gds-admin create-table --table {{ .Values.store.dynamodb.table }} --region {{ .Values.region }}
{{- end }}
{{- if .Values.externalService.enabled }}

Load balancer Service {{ include "global-discovery.externalServiceName" . }} exposes gRPC on port
{{ .Values.externalService.grpcPort }}{{ if gt (int .Values.externalService.httpPort) 0 }} and REST on port {{ .Values.externalService.httpPort }}{{ end }}. Its address:

  kubectl -n {{ $ns }} get service {{ include "global-discovery.externalServiceName" . }} -o jsonpath='{.status.loadBalancer.ingress[0].hostname}'

Point the regional Route53 record gds.{{ .Values.region }}.<env>.internal and this region's
entry of the latency record gds.<env>.internal at it (docs/networking.md).
