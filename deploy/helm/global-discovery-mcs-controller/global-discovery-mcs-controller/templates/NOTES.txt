Check that the controller is ready. Readiness means connected to GDS and, on
the leader, the cluster lease registered:

  kubectl -n {{ $ns }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl -n {{ $ns }} logs deploy/{{ $fullname }}

Export a Service to every cluster of the clusterset:

  kubectl -n <namespace> label service <name> gds.nvidia.com/export=true

The controller creates a ServiceExport of the same name and reports
conditions Valid and Ready on it. Other clusters then get a ServiceImport, a
derived Service derived-<hash> and EndpointSlices per source cluster in the
same namespace, which must exist there unless imports.createNamespaces is
set:

  kubectl get serviceexports,serviceimports -A
  kubectl -n <namespace> get endpointslices -l multicluster.kubernetes.io/service-name=<name>

A derived ClusterIP reaches remote pods only when the pod IPs of the source
clusters are routable from this cluster.
