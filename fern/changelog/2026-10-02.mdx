## Docs edition 1.0.0

One docs edition selector now covers Overview, Self-Managed, Compute Plane,
Observability, and Release Notes. The qualified combination is:

| Stack | Artifact version |
| --- | --- |
| Self-Managed | `1.0.1` |
| Compute Plane | `1.0.0` |
| Observability | `1.0.0` |

The docs edition is separate from stack artifact versions. No new stack
artifacts are introduced by this documentation release.

See the [compatibility matrix](../../docs/overview/compatibility-matrix.md),
[artifact manifest](../../docs/overview/manifest.md), and
[historical documentation](../../docs/overview/documentation-archive.md).
