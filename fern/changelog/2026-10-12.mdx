## Release 1.0.4

Release 1.0.4 is a docs-only patch. It keeps Self-Managed 1.0.1,
Compute Plane 1.0.0, and Observability 1.0.0. No stack upgrade is required
for this documentation update.

- Add the active-member OpenBao snapshot, backup-copy, and recovery Secret
  commands to the
  [0.6.1 to 0.6.2 upgrade](../../docs/overview/release-notes/0.6.1-to-0.6.2-upgrade.md).
- Add bounded Cassandra migration Jobs, exact schema-version checks, and
  executable service backfill steps to the
  [0.6.2 to 1.0.1 upgrade](../../docs/overview/release-notes/0.6.1-to-1.0.1-upgrade.md).
- Show the required tracing endpoint alongside the tracing token in
  cluster-registration examples and document the endpoint override.

The upgrade guides retain the recorded availability failures and rehearsal
limits. This documentation correction does not qualify an uninterrupted
production upgrade.
