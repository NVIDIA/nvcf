nvstor v{{ .Chart.AppVersion }} deployed

Namespace: {{ .Release.Namespace }}
Replicas:  {{ .Values.replicaCount }}

1. Check pod status:
   kubectl -n {{ .Release.Namespace }} get pods

2. View logs:
   kubectl -n {{ .Release.Namespace }} logs -f {{ include "nvstor-server.fullname" . }}-0

3. Access services:

   # Health check
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "nvstor-server.fullname" . }} 9101:{{ .Values.service.http.port }}
   curl http://localhost:9101/readyz

   # Native wire protocol
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "nvstor-server.fullname" . }} 9100:{{ .Values.service.grpc.port }}

   # S3 API
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "nvstor-server.fullname" . }} 9000:{{ .Values.service.s3.port }}

   # Metrics
   curl http://localhost:9101/metrics

4. Storage location: {{ .Values.storage.hostPath }}
