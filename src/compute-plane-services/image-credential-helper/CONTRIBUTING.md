# Contributing to image-credential-helper

This component is native to `NVIDIA/nvcf`. Follow the repository
[contribution guide](../../../CONTRIBUTING.md), local [build instructions](README.md)
and [release instructions](RELEASING.md). File issues and pull requests in
[NVIDIA/nvcf](https://github.com/NVIDIA/nvcf).

Main receives ongoing development. Maintenance fixes target the path-scoped
component branch documented in the release guide. The former standalone
repository's branch and bare-tag instructions no longer apply here.
