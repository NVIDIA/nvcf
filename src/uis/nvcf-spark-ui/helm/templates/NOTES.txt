{{- $values := .Values.nvcfSparkUi -}}
{{- $fullname := include "nvcf-spark-ui.fullname" . -}}
The NVCF Gateway UI is installed as {{ $fullname }} in namespace {{ .Release.Namespace }}.

{{- if $values.ingress.enabled }}

Open it through the ingress: http://{{ $values.ingress.host | default "<any node address>" }}{{ $values.ingress.path }}
{{- else if eq $values.service.type "NodePort" }}

Open it on the node port:
  kubectl -n {{ .Release.Namespace }} get service {{ $fullname }} -o jsonpath='{.spec.ports[0].nodePort}'
{{- else }}

Reach it with a port-forward:
  kubectl -n {{ .Release.Namespace }} port-forward service/{{ $fullname }} {{ $values.service.port }}
  then open http://localhost:{{ $values.service.port }}
{{- end }}

It reads the gateway key from Secret {{ $values.gateway.apiKey.secret }} (key {{ $values.gateway.apiKey.key }}). After the key rotates, run
helm upgrade to roll the pod.
