# NVCF 1.0 Release Notes

NVCF 1.0 is the first release in which the three Helm stacks are versioned
and released independently. Each stack starts its release history at 1.0.0
and advances on its own release train from here. See the
[compatibility matrix](../compatibility-matrix.md) for the stack releases that
are qualified to run together.

<Info>
Detailed changes, known issues, and compatibility notes for each stack will be
added before the release is finalized.
</Info>
