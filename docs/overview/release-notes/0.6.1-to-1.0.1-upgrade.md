# Upgrade from NVCF Self-Managed 0.6.1 to 1.0.1

The upgrade requires an intermediate 0.6.2 patch:

```text
0.6.1 -> 0.6.2 -> 1.0.1
```

1. Complete the [0.6.1 to 0.6.2 upgrade](/nvcf/self-managed/0.6.2/0-6-1-to-0-6-2-upgrade).
2. Require a healthy 0.6.2 deployment, including OpenBao, JWT operations,
   and the injector.
3. Follow the [0.6.2 to 1.0.1 upgrade](./0.6.2-to-1.0.1-upgrade.md).

The 0.6.2 procedure is currently a draft pending stable publication and live
upgrade qualification. Do not skip the patch or use the candidate as a
qualified source deployment. This page preserves the previous upgrade URL.

For an older installation, complete the documented upgrades to 0.6.1 first.
See the [release notes index](./index.md).
